# Community Science Museum Website
![museumreadme](https://github.com/user-attachments/assets/896d4c84-008d-47a7-b6f6-6b1e0931b42d)

This project is a website built for the **Community Science Museum**. The website is designed to provide information about the museum, showcase exhibits, and offer visitors easy access to important details such as opening hours, location, and events. 

The website was developed using **HTML**, **CSS**, and **JavaScript** to ensure it is accessible, visually appealing, and user-friendly.

## Features

- **Responsive Design**: The website adapts to different screen sizes, providing an optimized experience on both desktop and mobile devices.
- **User-friendly Interface**: Easy navigation and clear layout for museum visitors to explore.
- **Basic Styling**: CSS is used to style the webpage and create a visually engaging environment that reflects the theme of a science museum.

## Technologies Used

- **HTML**: Structure of the web pages and content.
- **CSS**: Styling and layout of the pages, including responsiveness.
- **JavaScript**: Interactive features and dynamic content.

## Installation

To view the website locally, follow these steps:

1. Clone the repository to your local machine:
    ```bash
    git clone https://github.com/EkremGursoy/semesterprosject
    ```

2. Navigate to the project folder:
    ```bash
    cd community-science-museum
    ```

3. Open `index.html` in your browser to view the website.
