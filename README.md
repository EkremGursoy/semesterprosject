# Community Science Museum - Website
![museumreadme](https://github.com/user-attachments/assets/b694fdd5-7f64-4920-a16c-74c07cfd8466)
Welcome to the **Community Science Museum** website! This platform is designed to provide visitors with easy access to the museum's exhibits, upcoming events, and educational resources. Whether you're a science enthusiast or a curious learner, our website is your digital gateway to the wonders of science!

## Features

- **Interactive Exhibits**: Learn about various science topics through engaging and informative exhibits.
- **Event Calendar**: Stay up-to-date with upcoming events, workshops, and special exhibitions.
- **Responsive Design**: The website is fully responsive, ensuring a great browsing experience on both desktop and mobile devices.
- **Educational Resources**: Access a collection of educational resources, articles, and science facts.
- **Contact and Location Information**: Find the museum's address, contact details, and directions to plan your visit.

## Getting Started

To run the Community Science Museum website locally on your machine, follow these steps:

1. Clone this repository to your local machine:
    ```bash
    git clone https://github.com/Ekrem Gursoy/semesterprosject
    ```

2. Navigate to the project folder:
    ```bash
    cd community-science-museum
    ```

3. Open the `index.html` file in your browser to view the website:
    ```bash
    open index.html
    ```

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Design**: Responsive design using media queries for a smooth user experience across devices.
